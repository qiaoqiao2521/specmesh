# Architecture Explorer

## Intent
用户要求把反复重画的架构图变成仓库维护的一部分，并放在 SpecMesh 作为面向人的入口。复用现有 Map/area/记忆边界，静态 HTML 展示真实职责、源码、验收状态和变更影响。

## Scope
- 通用 Python 构建器与离线 HTML/SVG 页面。
- 已审查 JSON 仅声明模块、展示位置、业务关系和显式检查；源码与实际结果分别提供结构与验收证据。
- GitHub Actions 自动生成可下载页面；不启用公开站点或常驻服务。
- SpecMesh 自身采用；独立私有项目的声明保留在其自己的仓库。

## Acceptance
- [x] 从当前源码生成内嵌数据的离线页面，包含桌面与手机布局。
- [x] 实现搜索、模块选择、源码导航、上下游及真实/假设变更影响，模板语法与契约已检查。
- [x] 未执行、失败、输入过期与区域阻塞明确区分；路径存在不冒充测试通过。
- [x] 复用 Map/area，维护声明不被生成器回写，规范与独立运行时不被绑定。
- [x] 负向回归与现有 Python 回归通过；CI 自动构建和失败传播已接入。
- [ ] 在真实浏览器完成桌面、手机与交互验收：当前浏览器执行与本地文件策略阻断，未冒充通过。

源码与页面产物的远端入口及具体验证结果见 progress.md；新增页面不代表公开站点已部署。
